
# Cryptography and Data Protection Lab

## About the Project

This project contains practical implementations of cryptographic techniques using Python. It was completed as part of my MSc Cyber Security practical work.

## Experiments

1. Symmetric Encryption and Decryption using Fernet.
2. SHA-256 Hashing for data integrity.
3. Password Protection using PBKDF2 and SHA-256.
4. RSA Asymmetric Encryption and Digital Signatures.

## Technologies Used

- Python 3.12.3
- Ubuntu (WSL)
- Visual Studio Code
- Python Cryptography Library

## Project Files

- symmetric.py
- hashing.py
- password_protection.py
- asymmetric.py

## How to Run

Install the required library:

```bash
python -m pip install cryptography
```

Run an experiment:

```bash
python symmetric.py
```

You can replace symmetric.py with the name of any other Python file.

## Learning Outcomes

- Understanding encryption and decryption.
- Generating SHA-256 hashes.
- Understanding secure password storage.
- Working with RSA public and private keys.
- Creating and verifying digital signatures.
